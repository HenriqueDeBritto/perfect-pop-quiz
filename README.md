# 🎵 Present Perfect Arena — Quiz Musical

Quiz em estilo arcade para aprender o **Present Perfect** do inglês usando trechos de músicas famosas (U2, Queen, Adele, Beatles, Bon Jovi e outras). Cada pergunta traz o clipe da música e uma explicação gramatical da resposta.

Trabalho desenvolvido na **Fatec São Sebastião**.

## Tipos de questão

- Múltipla escolha
- Verdadeiro ou falso
- Preenchimento de lacuna

## Como rodar no seu computador

### 1. Pré-requisitos

- [Node.js](https://nodejs.org/) versão 20 ou mais recente (baixe a versão **LTS**)
- [Git](https://git-scm.com/downloads) (opcional — dá para baixar o ZIP pelo GitHub)

### 2. Baixar o projeto

Com Git:

```sh
git clone https://github.com/HenriqueDeBritto/perfect-pop-quiz.git
cd perfect-pop-quiz
```

Ou, sem Git: no GitHub clique em **Code → Download ZIP**, extraia a pasta e abra um terminal dentro dela.

### 3. Instalar e iniciar

```sh
npm install
npm run dev
```

Depois abra no navegador o endereço que aparecer no terminal (algo como **http://localhost:5173**, linha `Local:`).

Para parar, pressione `Ctrl + C` no terminal.

> É preciso estar conectado à internet para os vídeos das músicas (YouTube) carregarem.
